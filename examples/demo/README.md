# Sample edit inputs

These files are invented so the recipe shape is visible without anyone's footage or transcript.

- `words.json` is word timing in output seconds.
- `keeps.json` is one keep, in raw video seconds.
- `joins.json` is empty because this sample is a single shot.
- The recipe that would drive it is `../recipe.example.json`. Point `edit`, `words`, `joins`, and the b-roll files at your own media. Footage stays outside this repo.
